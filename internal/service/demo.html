What this demonstrates

  1. Sending the same source and idempotency key again returns the original event.
  2. Sending different content with that key returns HTTP 409.
  3. The delivery carries a stable event ID and an HMAC signature for the receiver to verify.
  4. PostgreSQL mode preserves the event and attempt history after a restart. This demo mode keeps data in memory.
